## AI Reasoning Framework identity

The canonical AI object is one **AI Reasoning Framework** derived from the book's reasoning architecture, not a generic bundle of prompt products. Its core public protocol is:

1. Name the current representation.
2. State what the representation omitted.
3. Generate competing structural frames.
4. Preserve evidence and transfer status.
5. Name discriminating evidence.
6. Reframe or stop.

The framework must keep the distinction between a structure observed in a source discipline and a proposed transfer to another domain. Similarity is not proof of causal equivalence.
