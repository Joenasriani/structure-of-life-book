## Target

The page should sell first to readers who want stronger ways to structure problems, ideas, models and systems. It should also be immediately legible to AI builders, product people, researchers and creative technologists as a reusable structural library — without turning the book into a generic “AI book.”

The AI signal is earned through the book itself: state, constraint, memory, feedback, error, change, competing models, hidden variables, transfer between disciplines and testing the model against the world.

## Sales-page rules

- The book must remain the visual focus.
- The book must be understandable immediately.
- Keep one obvious primary purchase action.
- Keep the public sample easy to find.
- State the offer plainly as a **study system**, not as an inflated bundle claim.
- No generic AI copy or generic “future” language.
- No generic AI imagery: no brains, neural nets, glowing nodes, robots, circuitry, holograms, prompt windows, gradient clouds, abstract 3D blobs or synthetic tech scenery.
- No generic generative UI: no SaaS cards, pills, dashboards, glassmorphism, badge clutter, startup gradients, fake data panels or decorative interface chrome.
- Every visible device should come from the book’s actual structural logic.
- Color is functional, not decorative. Current domain register: **CODE / LIFE / MIND / SYSTEMS**.
- Cover language should imply a reusable reference system through the **Structure Index** and the actual book primitives: state, constraint, memory, feedback, error and change.
- Author credit stays visually secondary: `by J. NASR`.
